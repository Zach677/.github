# Contributing

Thank you for your interest. I maintain these projects in my free time, so a
short and clear report or pull request helps a lot.

If a repository has its own `CONTRIBUTING.md`, that file applies instead of
this one.

## Report a bug

1. Search the open and closed issues first.
2. If the bug is not there, open an issue. Include the steps to reproduce it,
   what you expected, what happened, the version of the project, and your
   operating system.

Issues are public. Do not put passwords, tokens, or personal data in an issue.

To report a security problem, use **Report a vulnerability** in the Security
tab of the repository when it is available. Do not open a public issue.

## Suggest a feature

Open an issue and describe the problem that you want to solve. A clear problem
is more useful than a finished design.

## Open a pull request

- For a small fix, open a pull request directly.
- For a larger change, open an issue first, so that we agree on the direction
  before you write the code.
- Keep one topic in one pull request.
- Follow the build and test instructions in the README of the repository.

## AI assistance

You can use AI tools. Say so in the pull request, and say how much they did.
You must understand the change, test it yourself, and be able to answer
questions about it.
